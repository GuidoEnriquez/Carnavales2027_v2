# Clarificaciones - Spec 009

| Tema | Decisión |
|---|---|
| Fuente visual | El brief del responsable de producto en `client/AGENTS.md` define el lenguaje visual, pero no habilita módulos diferidos. |
| Offline | El indicador puede reflejar el estado de conexión y la cola exploratoria existente; no se agregan ni se declaran operativas nuevas garantías Offline-First. |
| Confirmación de asignación | Se expresa como contexto claro de noche, especialidad y planillas en el home. No se crea persistencia ni un nuevo paso obligatorio sin API aprobada. |
| Edición de puntajes | Spec 007 prevalece: una decisión confirmada no es editable. La revisión es de solo lectura. |
| Total de puntos | Se puede mostrar como resumen visual cuando todos los scores tienen valor, pero no constituye resultados ni rankings oficiales. |
| App shell | La navegación administrativa conserva sus capacidades; el shell operativo del jurado prioriza contexto, progreso y conectividad. |
| Referencia visual 2026-09-01 | Las cinco pantallas entregadas por producto son la referencia de jerarquía, paleta, trama, etiquetas monoespaciadas y controles grandes para login, home, planilla y revisión. Se adapta a rutas y datos existentes. |
| "Modificar puntuaciones" en la referencia | No se implementa. Es incompatible con Spec 007: tras confirmar, `SCORED` y `NOT_PRESENTED` son solo lectura. |
| Confirmación de asignación en la referencia | No crea un paso operativo nuevo sin API aprobada. Puede inspirar el contexto visual del home, pero no altera el flujo de sesión o asignación. |
